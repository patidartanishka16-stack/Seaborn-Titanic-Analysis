# Titanic Data Visualization using Seaborn

## Project Overview

This project explores the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.
Different visualization techniques are used to understand passenger distribution,
survival patterns, fare distribution, and passenger classes.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations

The project includes:

- Passenger Class Distribution
- Survival by Sex
- Fare Distribution
- Fare Distribution by Passenger Class
- Survival Rate by Passenger Class

## Key Findings

- Pclass 3 had the highest number of passengers.
- Female passengers had a higher number of survivors compared with male passengers.
- Most passenger fares were concentrated in the lower fare range.
- Pclass 1 showed a higher fare distribution compared with other classes.
- Pclass 1 had the highest survival rate among the three passenger classes.

## Conclusion

The Titanic dataset was explored using Pandas and Seaborn.
Different visualizations were used to understand passenger distribution,
survival patterns, fare distribution, and differences between passenger classes.
The analysis shows clear differences in survival and fare across passenger groups.
